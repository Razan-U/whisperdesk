## 0.3.2-beta.18 — 28 жовтня 2026

Windows x64, embedded Python 3.12.10, наявні залежності встановленого beta.17.
112 tests passed, 0 warnings (`-W error`). Нові регресійні сценарії охоплюють
Job → UI controller → ETA calibration для mixed/fixed і Auto→CPU,
одноразове відновлення calibration v2 у v3 зі збереженням backup,
некоректні JSON/config payloads та UTF-8 PowerShell hardware probe.

GitHub Windows release CI: 109 passed / 3 skipped (FFmpeg fixture generation),
Setup / Update / Launcher build succeeded. Release commit: 0bb86f6.

Після встановлення опублікованого Update beta.17 → beta.18 перевірено:
- UI повідомив успішне оновлення, усі Python-модулі відповідають release source;
- history.json і queue.json збережено побайтово до нових тестових прогонів;
- усі чотири моделі та користувацькі налаштування збережені;
- calibration v3 створено, попередній файл залишився як backup;
- installed-package regression: 112 passed / 8,37 с, warnings-as-errors;
- fixed/en + turbo + Auto→CUDA, 10 хв аудіо: 45,391 с (ETA 25–60 с);
- mixed UK/EN/RU на тому самому діапазоні: 89,609 с (ETA ≈1–2 хв);
- fixed-прогін збільшив лише fixed bucket 7→8; mixed-прогін збільшив лише
  mixed bucket 4→5, fixed залишився 8;
- обидва сеанси мають complete JSONL, збережений TXT і done History record;
- повторний UTF-8 hardware probe не дає reader-thread decoding errors.

Вбудований updater завантажив і перевірив SHA-256 пакета. Admin-встановлення
завершив власник ПК: керування підвищеним вікном з агента завершилося timeout,
а спробу transactional update без адміністратора Windows відхилила WinError 5.

Перевірка не включала clean install, довгий повторний ETA acceptance run або
реальний GPU fault; Auto→CPU routing покрито регресійним тестом.
PR #3 залишається відкритим, Stable 0.4 у межах цього тесту не випускався.

## Історична перевірка 0.3.0

28 вересня 2026. Linux x64, Python 3.12, Qt offscreen.

- 27 автоматизованих тестів пройдено.
- Перевірено діапазони WAV/MP3/M4A/OGG, обмежений аудіобуфер, часові позначки,
  UTF-8, видимість пояснення лише для змішаного режиму.
- Журнали контрольних точок: пошкоджений хвіст, помилка посеред фрагмента,
  повтор без дублювання, виявлення зміненого початкового файлу.
- Імітовано аварійний вихід GPU-процесу: Авто повторює на CPU один раз;
  явний CUDA, повторний збій CPU та зупинка користувачем не спричиняють повтору.
- Перевірка GPU повністю споживає лінивий генератор транскрипції; помилка
  декодера виявляється до обробки користувацького аудіо.
- Завантаження NVIDIA: відхилення хибного SHA-256, продовження HTTP Range,
  коректний перезапуск завантаження, якщо сервер ігнорує Range.
- Оновлювач: збереження data-path.txt і даних користувача, резервна копія,
  відкат при помилці перейменування, відмова при зайнятому QLockFile.
- Реальна base / CPU INT8 в окремих spawn-процесах: черга з трьох записів,
  відсутній другий файл → готово / помилка / готово, TXT збережено.
- Реальний запис 55,51 с: зупинка на 23,75 с, продовження до кінця;
  раніше збережені рядки незмінні.
- Метадані чотирьох офіційних Windows wheels NVIDIA взято з PyPI з SHA-256;
  через центральні каталоги ZIP підтверджено наявність необхідних DLL.
- NSIS скомпілював окреме оновлення і повний інсталятор. Обидва архіви
  пройшли 7-Zip integrity test. Код із розпакованого оновлення збігається
  з протестованим вихідним кодом.

## Межі перевірки

Версію 0.3.0 не запускали на справжній Windows чи NVIDIA. Підтвердження
користувача про успішне встановлення стосувалося попередньої версії 0.2.
Автоматизовані тести не замінюють перевірку DLL-завантаження та драйвера
на RTX 3050 Laptop. Повністю завантажувати і запускати NVIDIA wheels на Linux
не намагалися; перевірено їх метадані та вміст каталогів ZIP.
Інсталятори не підписано цифровим підписом видавця.

## Короткий приймальний тест Windows

1. Закрити встановлену 0.2 та запустити Update-0.3.0.
2. Перевірити наявність попередніх налаштувань, моделей, черги й текстів.
3. Запустити короткий запис з base / Авто з доступом до інтернету.
4. Дочекатися встановлення компонентів NVIDIA та GPU-перевірки.
5. Перевірити діагностику; якщо відбувся перехід на CPU, скопіювати причину.
6. Перевірити зупинку/продовження і другий запуск після відключення інтернету.
7. На другому ПК встановити Setup-0.3.0, перевірити ярлик і base / CPU.
