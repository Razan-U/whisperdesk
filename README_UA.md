# WhisperDesk 0.3.1 — Windows

Локальна транскрипція аудіо, черга файлів та відновлення після переривання.
Світла й нічна ретро-теми, 8 акцентних кольорів, іконка диктофона.

## Встановлення одним файлом

1. Запустіть **WhisperDesk-Setup-0.3.1.exe** на Windows 10/11 x64.
2. Підтвердьте стандартний запит Windows на встановлення.
3. Залиште папку **D:\WhisperDesk** або виберіть іншу. Якщо D немає,
   інсталятор запропонує папку WhisperDesk у Program Files.
4. Завершіть встановлення й запустіть **WhisperDesk** з ярлика на робочому столі.
5. На першому запуску автоматично завантажиться базова модель `base`.
   Для цього потрібен інтернет. Якщо завантаження перервано, повторіть його
   через Налаштування → Моделі або просто запустіть чергу з base.

Python, Qt, засоби читання аудіо та Microsoft Visual C++ Runtime уже включені
в інсталятор. Окремо встановлювати їх не потрібно. Після завантаження потрібних
моделей розпізнавання працює офлайн. Модель не включена в EXE.
Інсталятор не має цифрового підпису видавця. Встановлення та запуск на реальній
Windows ще не перевірено в середовищі розробки; див. VALIDATION.md.

## Оновлення та канали Stable / Test

Версія **0.3.1** додає автоматичні оновлення через GitHub Releases. Перехід
з 0.3.0 на 0.3.1 потрібно виконати вручну один раз: закрийте WhisperDesk і
запустіть **WhisperDesk-Update-0.3.1.exe**. Після цього наступні версії програма
може знаходити та встановлювати сама.

- **Stable** бачить тільки стабільні Releases.
- **Test** також бачить prerelease-версії (beta / RC).
- Автоматична перевірка виконується не частіше одного разу на 24 години.
- Ручна перевірка доступна у **Налаштування → Оновлення**.
- Якщо транскрипція активна, доступна дія **Оновити після завершення черги**:
  робота не переривається, а updater завантажується у фоні.
- Пакет стає доступним для запуску лише після перевірки SHA-256.
- Після успішного оновлення WhisperDesk перезапускається та показує нову версію.

Оновлюється лише код застосунку. Моделі, налаштування, черга, текст і шлях
до даних зберігаються. Попередній код залишається в `app-backup-*` біля `app`.
Перед завершенням updater виконує smoke-test нового коду; якщо він не проходить,
автоматично відновлюється попередня папка `app`.

## NVIDIA та режим «Авто»

CPU залишається початковим режимом для сумісності зі слабшими ноутбуками.
При першому використанні NVIDIA CUDA або Авто з виявленою NVIDIA програма
завантажує офіційні бібліотеки NVIDIA у власну папку даних: приблизно 1,1 ГБ.
Потрібно щонайменше 3 ГБ вільного місця на етапі встановлення. Архіви
перевіряються за SHA-256; після встановлення зайві завантажені архіви видаляються.
Завантаження можна зупинити та продовжити. Глобальні CUDA/PATH не змінюються.
Драйвер відеокарти має бути встановлений у Windows; застосунок його не замінює.

Перед транскрипцією виконується коротка перевірка обчислень на GPU.
У режимі **Авто** помилка GPU, нестача відеопам'яті або аварійний вихід процесу
спричиняє один повтор на CPU з останньої контрольної точки. Скасування
користувачем не запускає повтор. У явному режимі **NVIDIA CUDA** помилка
залишається видимою — примусового переходу на CPU немає.
Пояснення переходу на CPU та помилки вибраного файлу можна переглянути й
скопіювати в окремому полі діагностики над прогресом.

## Якщо вже встановлено версію 0.1

Завершіть її роботу й установіть нову версію в окрему запропоновану папку.
У Налаштуваннях є кнопка **Перенести моделі з 0.1**: вона переносить наявні
моделі зі стандартної старої папки, щоб не завантажувати їх знову.
Неіснуючі в новій папці моделі переносяться, наявні не перезаписуються.
Після перенесення стара версія не матиме цих моделей.

Старі JSONL-сеанси можна відкрити для перегляду та TXT-експорту. Автоматичне
продовження обчислень доступне для сеансів 0.2 з контрольними точками.
Стару папку програми, записи та текстові файли інсталятор не видаляє.

## Черга й налаштування файлів

- **Додати файли**: виберіть кілька аудіозаписів або перетягніть їх у вікно.
- Нові файли отримують поточні значення мови, моделі й ресурсів.
- Виберіть рядок черги, змініть налаштування й натисніть **Застосувати до файлу**.
- **До всіх нових у черзі** застосовує мову, модель та ресурси до ще не розпочатих
  завдань. Власні часові діапазони цих завдань залишаються без змін.
- Стрілки змінюють порядок; **Прибрати** видаляє рядок черги, але зберігає його сеанс.
- **Почати чергу** обробляє по одному файлу. Брак моделі запускає її завантаження.
  Уже готові завдання пропускаються, помилкові та перервані повторюються/продовжуються.
- **Зупинити файл** зберігає його контрольну точку та переходить до наступного.
- **Зупинити чергу** зупиняє поточний файл і не запускає наступні.
- Помилка одного файлу не блокує наступні. Наведіть курсор на рядок із помилкою,
  щоб прочитати її. За відсутності джерела поверніть аудіо за початковим шляхом.
- TXT зберігається окремо для кожного сеансу; ручний експорт дозволяє вибрати ім’я.

## Відновлення після помилки

Після кожного завершеного фрагмента програма записує текст, позицію та стан мови
у журнал, скидає буфер на диск. Збереження одного фрагмента є неподільною
контрольною точкою: незавершений фрагмент повторюється після відновлення.
Завершений текст повторно не додається. Тиша теж просуває контрольну точку.

При повторному запуску програма пропонує продовжити незавершені завдання.
Черга, порядок і налаштування зберігаються. Для завершеного частково сеансу
мова, модель та діапазон заблоковані, щоб не змішувати несумісні результати;
CPU/GPU та кількість потоків можна змінити після зупинки. Щоб змінити мову чи
модель, додайте аудіо як нове завдання.

Якщо розмір або дата зміни аудіо відрізняються, відновлення блокується:
додайте оновлений файл заново. Сам аудіофайл програма не змінює й не копіює.
Автозбереження не захищає від фізичної несправності диска або видалення файлів.

## Мови, діапазон та продуктивність

- Українська → українська; англійська → англійська: без перекладу.
- Змішаний UK / EN / RU: вибір мови приблизно кожні 6–8 секунд аудіо.
  Пояснення цього режиму видно тільки при його виборі.
- Короткі іншомовні вставки всередині речення, суржик, шум і одночасна розмова
  залишаються складними випадками. Якість реальних змішаних розмов ще потребує оцінки.
- Діапазон — весь файл або один інтервал `год:хв:сек`. Позначки відповідають
  оригінальному аудіо, навіть при обробці його середини.
- Прогрес враховує оброблену тривалість вибраного інтервалу разом із тишею.
  Залишок часу приблизний, оновлюється після завершення фрагментів.
- WAV, MP3, M4A, FLAC, OGG, Opus та інші формати, підтримувані PyAV.

| Комп’ютер | Початковий вибір |
|---|---|
| i5-11400H, 16 ГБ RAM | `small`, CPU, економний, потоки «Авто» |
| Слабший ThinkPad, орієнтовно 8 ГБ RAM | `base`, CPU, економний, 2 потоки |
| Потужніший ПК | Порівняйте `small`, `turbo`, `large-v3` на короткому записі |

`base` ≈150 МБ на диску; `small` ≈500 МБ; `turbo` ≈1,7 ГБ; `large-v3` ≈3,1 ГБ.
Ці числа не є вимогами до RAM. Швидкість на ваших ПК ще не вимірювалася.
Одна модель завантажується на один файл; після завершення процес звільняє пам’ять.
Довге аудіо читається частинами. Пакетного одночасного розпізнавання немає.

## Дизайн

Перемикач світлої/нічної теми — вгорі праворуч. Налаштування → 8 акцентних
кольорів. Вибір запам’ятовується. Бежеві поверхні в нічному режимі стають
темно-коричневими. Іконка залишається у погодженій кремово-коричневій палітрі.

## Папки

При стандартному встановленні на D: `D:\WhisperDesk\Data`.
При виборі іншої звичайної папки — її підпапка `Data`.
Для стандартного Program Files використовується `%PROGRAMDATA%\WhisperDesk`.
Фактичний шлях видно в Налаштуваннях; там же є кнопка відкриття папки.

- `models` — моделі;
- `sessions` — журнали `.jsonl`, текст `.txt`, помилки `.error.log`;
- `queue.json` — черга;
- `settings.json` — налаштування;
- `startup-error.log` — діагностика запуску встановленої програми.

У JSONL міститься текст та шлях до початкового аудіо. Файли сеансів не
очищуються автоматично. Видалення програми залишає моделі й дані користувача.
Дві копії програми не можуть одночасно писати до однієї папки даних.

## Запуск з вихідного коду

Як альтернатива інсталятору: Python 3.12 x64 → Install.bat → Start.bat.
Папка даних обирається на D за його наявності, інакше у LOCALAPPDATA.
Для розробки змінна `WHISPERDESK_DATA` задає окрему папку даних.

Тести: `python -m pip install pytest`, потім `python -m pytest -q` з папки проєкту.
Тести MP3/M4A/OGG потребують FFmpeg лише для створення тестових аудіофайлів.

## Збірка

У `installer/` є сценарії NSIS, підготовка payload та інструкція BUILD.md.
EXE-інсталятор містить ізольований CPython 3.12.10, Windows x64 wheels та
офіційний Visual C++ Redistributable. На цільовому ПК pip не запускається.
Транзитивні версії та SHA-256 wheels зафіксовано у BUILD-MANIFEST.json.
Ліцензії залежностей збережено разом з пакетами; вихідний код програми — MIT.
